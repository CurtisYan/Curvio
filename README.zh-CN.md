# Curvio

<p align="right">
  <a href="./README.md"><kbd>English README</kbd></a>
</p>

Curvio 是一个开源公益记录社区，用来记录捐赠、善意行动和开放贡献。

它不是募捐平台，不提供个人收款入口，不抽成，也不做金额排行榜。它更像一个安静的公益档案：让每个人可以把长期发生的善意保存下来，而不是把善事变成一次性的展示。

Curvio 第一版主要支持三类记录：

- 捐赠记录：记录自己支持过的公益项目或机构。
- 善意行动：记录非金钱类的帮助、志愿服务、资源分享等。
- 开放贡献：记录免费、开源、有公共价值的项目。

Curvio 有意把边界收窄。它不提供私人收款链接，不抽成，不按金额给人排序，也不把点赞、徽章当成体验中心。一次小额捐赠、一件安静的志愿行动、一个长期维护的开源工具，都可以被同样认真地记录下来。

## 为什么做 Curvio

我做 Curvio 的起点很简单：想记录学生时期那些并不大的捐赠。金额不大，但习惯很重要。

很多公益产品更关注活动、紧迫感和转化，这些在合适的场景里当然有价值。但 Curvio 想保留另一个空间：一个平静的公开档案，让长期发生的善意可以积累、回看，并温和地影响更多人参与。

## 产品原则

- 记录优先，社交其次。
- 真实优先，数据其次。
- 长期坚持优先，短期热度其次。
- 隐私和用户控制是产品的一部分，而不是事后补丁。
- 开源是默认姿态，社区可以检查、改进，也可以复用这份工作。

## Curvio 支持什么

目前 Curvio 支持公开个人主页、公开/私有记录、金额隐藏、匿名发布、记录图片公开/私有可见、中英文双语、公开档案搜索，以及官方公益平台入口。

隐私上，Curvio 只收集运行账号、主页、记录、关注关系和展示偏好所需的数据。因为它不处理捐款，所以不会采集银行卡或支付扣款信息。

## 技术栈

Curvio 使用 Next.js、React、Supabase、Cloudflare R2、Cloudflare Turnstile，并通过 OpenNext 部署到 Cloudflare。

本地开发：

```bash
npm install
npm run dev
```

然后打开 `http://localhost:3000`。

复制 `.env.example` 为 `.env.local`，并填写 Supabase、R2、Turnstile 和站点 URL 等配置。
